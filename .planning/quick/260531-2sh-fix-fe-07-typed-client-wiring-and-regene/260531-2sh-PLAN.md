Package facts:
- openapi-fetch 0.17.0 — exposes `createClient<paths>(...)` returning a client with `.use(middleware)`. A Middleware is an object with an optional `onRequest({ request }) => Request | undefined`. Mutate `request.headers.set(...)` and return `request`.
- openapi-react-query 0.5.4 — default export is named `createClient` in source; per the task spec import it as `createQueryClient` to avoid name collision with openapi-fetch's `createClient`. Call `createQueryClient(apiClient)` → returns the `$api` object with `.useQuery(...)`, `.useMutation(...)`, etc.
- Test runner: vitest 2.1.8 (`npm test` = `vitest run`). gen:api = `openapi-typescript ./openapi.json -o ./lib/api/generated.ts`.
