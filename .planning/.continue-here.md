## Critical anti-patterns (do NOT repeat)

| Pattern | Prevention |
|---------|------------|
| False coverage on local Python 3.9 | Coverage ONLY on py3.12 (`/tmp/umraa-py312`). |
| CI silently skipped on conflicting PRs | If `gh pr checks N` empty → `gh pr view N --json mergeable`; merge `origin/planning` into the branch. |
| Stale `.planning` push reverts a merge | ALWAYS `git fetch && git reset --hard origin/planning` after each merge before the next `.planning` doc commit. |
| AI-trace watermarks | Plain conventional commits — no `Co-Authored-By: Claude`, no robot emoji. ("claude" as the Action product name is fine.) |
| Self-approving own PRs | Own PR → `gh pr merge N --squash --admin --delete-branch` (no self-approve). Teammate PR → `gh pr review N --approve` first. |
| Review action skips self-modifying workflow PRs | By design (must match default branch). Not a failure. |
| Board status drifts back | A project automation occasionally re-fires (saw #14 revert to "In review"); re-set closed issues to Done and re-verify. |
