SUMMARY OF ISSUES
================================================================================

CRITICAL BUG #1: citations=null → TypeError crash (not caught)
  File:         backend/app/reasoning/core.py, line ~115
  Root cause:   raw.get("citations", []) returns None when JSON value is null;
                iterating None raises TypeError.
  Why it's bad: The TypeError is NOT caught by the except ValueError in
                run_reasoning (line ~262). It propagates as a 500 error to the
                /packet endpoint — the demo path. The previous PR's openFDA
                code had a similar "+AND+" encoding bug masked by test fixtures;
                this is the same class of latent crash.
  Proof:        >>> json.loads('{"citations": null}').get("citations", [])
                None  # not []
  Fix options:
    Option A: Change comprehension to
                 for c in (raw.get("citations") or [])
              The "or" coalesces None → [].
    Option B: Guard before comprehension:
                 raw_citations = raw.get("citations", [])
                 if not isinstance(raw_citations, list):
                     raw_citations = []
    Option C: Add except (ValueError, TypeError) to the run_reasoning try.
  RECOMMENDATION: Option A (one-line change, most defensive).

CRITICAL BUG #2: Zero-citation hypothesis survives verification (spec violation)
  File:         backend/app/reasoning/core.py, verify_citations ~line 196
  Root cause:   After filtering to known_citations, the loop runs zero times,
                valid stays True, and the hypothesis with 0 citations is kept.
  Why it's bad: PRD §1 states "No resolvable citation → not shown." A hypothesis
                with 0 citations has no evidence and should never reach the UI.
                The task prompt says "each suggestion must cite its sources."
  Fix:          Change line:
                  if valid:
                to:
                  if valid and known_citations:
  RECOMMENDATION: Fix this. It's two characters.

CRITICAL GAP #3: No test for citations=null or zero-citation cases
  The test suite covers happy-path, ValueError cases, and dropped-citation
  cases, but DOES NOT test:
    - citations=null in a hypothesis (this would catch bug #1)
    - zero-citation hypothesis surviving verification (this would catch bug #2)
    - citations="malicious_string" (non-list edge case)
  RECOMMENDATION: Add tests for these three cases.

MINOR #4: Dead code
  - _BARE_TAG_RE defined but never used (core.py line ~33)
  - import importlib unused (test_reasoning_config.py line 3)
